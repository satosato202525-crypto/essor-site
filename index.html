01 新しい商品・サービスを形にしたい

アイデアを、「判断できる商品案」へ。

「こんな商品があれば」というアイデアだけでは、商品化には進めません。

顧客ニーズ、商品コンセプト、原価、製造条件を一つずつ整理し、売れそう・つくれそう・利益が出そうを確かめながら、商品化までの道筋を組み立てます。

こんなときに

  • 新しい商品やサービスを考えたいが、時間や人が足りない
  • アイデアはいくつもあるが、どれを進めるべきか決められない
  • 作ってみたいものはあるが、誰に売るのかが曖昧
  • 試作品はあるが、本当に顧客に選ばれるか確かめたい
  • 試作まではできたが、量産や採算に不安がある

実際に行うこと

  • 既存商品や新商品アイデアを整理し、取り組む優先順位を決める
  • 「誰に」「どんな価値を届けるか」を整理し、商品コンセプトを言語化する
  • 顧客価値・市場性と実現可能性の両面から商品案を比較する
  • 自社商品や競合商品との比較から、改善すべき点を整理する
  • 技術・品質・生産体制・原材料調達など、量産前に確認すべき項目を洗い出す

成果物の例

  • 商品コンセプト整理シート
  • 商品アイデア優先順位表
  • 顧客ヒアリング・アンケート設計
  • 競合・ベンチマーク比較表
  • 商品化・量産化チェックリスト
  • 試作から量産までの課題整理表
  • 原価・利益の簡易シミュレーション
  • 商品化までのアクションプラン

02 原価と価格を見直して、利益を残したい

「売れている」から、「儲かっている」へ。

材料費、人件費、エネルギー費、物流費が上がれば、同じ価格で売り続けるほど利益は減ります。

商品・取引ごとの採算を整理し、どこで利益が失われているのか、いくらで売れば必要な利益が残るのかを数字で確認します。価格改定の根拠も整理します。

こんなときに

  • 売上はあるのに利益が残らない
  • 原材料費や人件費の上昇を価格に転嫁できていない
  • 儲かっている商品・取引が分からない
  • 値上げしたいが、いくら上げるべきか判断できない
  • 取引先へ値上げの理由をうまく説明できない

実際に行うこと

  • 商品・製品ごとの売上、原価、利益を整理する
  • 材料費、人件費、物流費など、利益を圧迫している要因を特定する
  • 限界利益と必要販売数を確認する
  • 値上げの根拠となる数字を整理する
  • 競合優位性を見出し、値上げしても選ばれる商品へ再定義する

成果物の例

  • 商品・製品別採算表
  • 原価構造の見える化資料
  • 利益改善シミュレーション
  • 価格改定シミュレーション
  • 値上げの説明資料
  • 利益改善アクションプラン

Ⅱ現場を整える

03 現場のデータから、改善する場所を見つけたい

「忙しい」を、改善すべき場所が分かる数字に変えます。

現場が忙しい、効率が悪い、出来高が安定しない。こうした問題を感じていても、どこで何が起きているのかが分からなければ、改善には進めません。

作業時間、生産量、不良、停止などを測り、工程、時間帯、作業者、品種などの違いから、ばらつきやロスが発生している場所を見つけます。

まずは現状を数字で捉え、どこから手をつけるべきかを明らかにします。

こんなときに

  • 現場は忙しいが、どこに原因があるか分からない
  • どの工程から改善すればよいか判断できない
  • 工程によって忙しさや出来高に差がある
  • 出来高、不良、停止時間が安定しない
  • データは取っているが、改善に活用できていない

実際に行うこと

  • 現場を確認し、問題を捉えるために何を測るかを決める
  • 作業時間、生産量、不良、停止などのデータを収集・整理する
  • 工程、時間帯、作業者、品種などによる違いを比較する
  • ばらつきやロスを見える化し、ボトルネックを特定する
  • 改善効果と着手しやすさから、優先順位と確認指標を決める

成果物の例

  • 現場データ分析レポート
  • 作業時間・サイクルタイム分析表
  • 工程別の時間・能力比較表
  • 工程別のロス一覧
  • 現状工程フロー図
  • グラフ・見える化資料
  • データ収集用フォーマット
  • 改善優先順位表
  • 改善前後の確認指標
この課題について相談する 初回60分無料
04 生産の流れを整えたい

「頑張って回す現場」から、「仕組みで回る現場」へ。

改善する工程が分かっていても、作業方法や人員配置を変えなければ、現場の流れは変わりません。

人によってやり方が違う。工程間で待ちや滞留が発生する。一部の工程に仕事が集中する。こうした状態に対して、作業の順序、役割分担、人員配置、設備、レイアウトを組み直します。

今ある人・設備・スペースを活かし、無理なく続けられる作業と工程の形をつくります。

こんなときに

  • 人によって作業方法、時間、品質に差がある
  • 工程間で待ちや仕掛品の滞留が発生している
  • ボトルネックは分かっているが、解消方法が決まっていない
  • 人を増やさずに生産量を増やしたい
  • 作業方法、人員配置、レイアウトを見直し、標準化したい

実際に行うこと

  • 改善する工程を確認し、目指す生産の流れを決める
  • 作業の順序や方法を見直し、待ち、運搬、手戻りを減らす
  • 工程間の能力差を整え、人員配置や作業分担を組み直す
  • 設備や治具の使い方、レイアウトを見直す
  • 改善案を試し、標準作業と実行・定着の進め方を決める

成果物の例

  • 改善後の工程フロー図
  • 作業方法・作業手順の改善案
  • 標準作業票
  • 標準時間一覧
  • 人員配置・作業分担案
  • 工程間の能力バランス改善案
  • レイアウト改善案
  • 試行・効果確認記録
  • 改善実行計画
  • 定着確認用チェックリスト

05 AIやデジタルツールを、仕事に使える形にしたい

「何ができるか」より、「どの仕事を楽にできるか」から考えます。

AIやデジタルツールは、導入すること自体が目的ではありません。

記録、転記、集計、資料作成、情報検索。日々の仕事の中で、時間がかかっている作業や繰り返しの作業を見つけます。

既製のサービスで十分ならそれを使い、なければ簡単なツールを作ります。

こんなときに

  • AIに興味はあるが、自社で何に使えるか分からない
  • Excelや紙での集計作業に時間がかかっている
  • 同じ入力や転記を何度も繰り返している
  • 情報を探したり資料を作ったりする時間を減らしたい
  • 市販システムを入れるほどではないが、少し便利にしたい

実際に行うこと

  • 日々の業務を洗い出し、時間のかかっている作業を整理する
  • 費用と効果を比べ、優先順位をつける
  • 小さな範囲で試し、実際の仕事で使えるか確認する
  • 必要に応じて簡単な集計ツールや業務用アプリを作成する
  • 導入後の使い方や運用方法まで整理する

成果物の例

  • 業務棚卸し・改善候補一覧
  • AI・デジタル活用マップ
  • 業務改善ツール
  • 簡易アプリ
  • 操作手順書
  • 導入前後の効果確認表

06 補助金も活用しながら、新しい取り組みを進めたい

補助金ありきではなく、「何を実現したいか」から考えます。

まず整理するのは、「どの補助金を使うか」ではなく、何のために投資し、会社をどう良くしたいのかです。

投資の目的、費用、期待する効果、収益への影響、実施スケジュールを整理したうえで、活用できる公的支援制度があるかを検討します。

こんなときに

  • 設備投資を考えている
  • 新しい取り組みに使える支援制度を知りたい
  • 投資額に対して、どの程度の効果が必要か整理したい
  • 設備を入れたいが、投資の妥当性を判断できていない
  • やりたいことはあるが、計画として整理できていない

実際に行うこと

  • 現在の課題と投資の目的を整理する
  • 導入する設備・取り組みと期待する効果を整理する
  • 売上増加、原価低減、生産能力向上などの効果を数字で検討する
  • 投資額と収益への影響をシミュレーションする
  • 活用可能性のある補助金・公的支援制度の情報を整理する

成果物の例

  • 設備投資・事業計画整理シート
  • 投資効果シミュレーション
  • 収支・資金計画の整理資料
  • 実行スケジュール
  • 公的支援制度の比較整理表

Essor

屋号について

Essor（エソール）は、フランス語で「飛翔」を意味する言葉です。

食品工場の中には、値段に見合わないほどの技術が入っています。何度も試作を重ねてたどり着いた配合。一つずつ条件を詰めていった工程。書類にも数字にも残らないまま、担当者の手に蓄えられた判断。

けれどその中身は、買う人のところまで届いていないことがほとんどです。安く見られてしまうのは、技術が足りないからではありません。伝わっていないからです。

つくっているものの中身を、余すところなく伝えたい。それが、この仕事を選んだ理由です。

会社にも、翼を広げる瞬間があると思っています。新しい設備を入れる。新しい商品を出す。次の世代に引き継ぐ。そのときに必要なのは、飛び立つまでの助走です。

私は、その歩みに伴走し、企業が飛躍するサポートをします。
